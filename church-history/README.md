# Church History site (moved)

The Church History site now lives in its own repository,
[trogers34/church-history](https://github.com/trogers34/church-history), and is published at
**https://trogers34.github.io/church-history/**. Its full history was carried over.

`https://trogers34.github.io/trogers-toolkit/...` send visitors to the same page on the new site.
